### Bảng xưng hô chính

### Tự xưng

| Ai xưng | Cách xưng | Context |
|---|---|---|
| Nam (thân) | **Na** (나) = "tôi" | Bạn bè, người thân |
| Nam (lịch sự) | **Jeoneun** (저는) = "tôi" | Trang trọng, người lớn |
| Nữ (thân) | **Na** (나) | Bạn bè |
| Nữ (lịch sự) | **Jeoneun** (저는) | Trang trọng |
| Nữ gọi nam lớn | **[Name] oppa** thay "tôi" | Khi nói với oppa |

### Xưng hô khi làm tình

| Context | Cách gọi | Ghi chú |
|---|---|---|
| Nữ gọi nam (passionate) | **Oppa...!** / **Oppa, harder...** | Mặc định |
| Nữ gọi nam (submissive) | **Oppa, em thuộc về oppa...** | Kinky |
| Nam gọi nữ (intimate) | **[Name]-a...** / **Jagiya** (자기야 = darling) | Thân mật |
| Nam gọi nữ (dominant) | **[Name], ngoan nào...** | Command |
| Cả hai (climax) | **Oppa!** / **Jagiya!** / **Ahh...!** | Bản năng |

### Context variations

| Tình huống | Xưng hô | Ví dụ |
|---|---|---|
| Lần đầu gặp (formal) | **[Name]-ssi** (씨) = Mr./Ms. | "Granger-ssi, chào em" |
| Thân quen (informal) | First name only | "Hermione, lại đây" |
| Rất thân (intimate) | **[Name]-a** / **[Name]-ah** (suffix) | "Ginny-a, anh nhớ em" |
| Tức giận | **Ya!** (야!) = "Ê!" | "Ya! Draco, im đi!" |
| Xin lỗi | **Mianhae** (미안해) / **Joesonghae** (죄송해) | "Mianhae, oppa" |
| Cảm ơn | **Gomawo** (고마워) / **Gamsahamnida** (감사합니다) | "Gomawo, unnie" |

### Cấm tuyệt đối

- ❌ "chị" thay "unnie"
- ❌ "em" thay "unnie" (nữ-nữ)
- ❌ "mày – tao"
- ❌ "con bé" (nam gọi nữ khinh miệt)

## Quy tắc áp dụng

1. **Chọn 1 style chính** hoặc **mix rõ ràng** trước khi bắt đầu viết
2. **Nhất quán xuyên suốt** toàn truyện
3. **Nếu đổi style giữa truyện** (vd: chuyển từ nguyên tác sang tiên hiệp ở ARC 2) → báo rõ trong outline
4. **Tự xưng** cũng cần thống nhất:
   - Nguyên tác HP: "I" / "me"
   - Hàn Quốc: "em" / "tôi" (nữ) / "anh" (nam)
   - Tiên hiệp: "đệ" / "muội" / "tại hạ" / "bần đạo"
   - Kiếm hiệp: "đệ" / "sư đệ" / "tại hạ" / "lão phu"
   - Nhật Bản cổ: "sessha" / "watakushi"
   - Cyberpunk: "this unit" / "I"
5. **Khi làm tình**: xưng hô có thể thay đổi (vd: từ "Oppa" → "Anh ơi...", từ "Sư huynh" → "Huynh...")
6. **Context quyết định xưng hô**: Lần đầu gặp = formal, thân quen = informal, intimate = special
7. **Edge cases**:
   - Khi tức giận: xưng hô có thể thay đổi tạm thời (vd: "Oppa" → "Ya!" trong Hàn)
   - Khi buồn: xưng hô trở nên dịu dàng hơn
   - Khi joking: có thể dùng xưng hô mock (vd: "Boss" thay "Professor")
